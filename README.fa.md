# فارسی‌ساز Sun Macro برای Odoo 19

این پروژه یک ماژول رایگان و متن‌باز برای بهبود تجربه فارسی در **Odoo 19** است و توسط **Sun Macro System** توسعه داده شده است.

**نام فنی ماژول:** `sun_macro_persian_localization`  
**نسخه:** `19.0.2.0.0`  
**مجوز کد:** LGPL-3.0

## امکانات نسخه 19.0.2.0.0

- فعال/غیرفعال‌سازی چیدمان RTL در وب‌کلاینت Odoo
- انتخاب فونت فارسی بین Vazirmatn و Shabnam
- نمایش اختیاری اعداد فارسی در فیلدهای عددی رایج شامل عدد صحیح، اعشاری و پولی
- ابزارهای پایتونی تبدیل تاریخ میلادی و جلالی با `jdatetime`
- بخش اختصاصی تنظیمات فارسی‌سازی در Settings

## وضعیت تاریخ شمسی

در این نسخه، تنظیم مربوط به تاریخ شمسی و ابزارهای تبدیل تاریخ در سمت پایتون وجود دارد. **جایگزینی کامل Date/DateTime Picker خود Odoo با تقویم جلالی، به‌عنوان قابلیت تکمیل‌شده این نسخه اعلام نمی‌شود.**

## نصب وابستگی

```bash
pip install jdatetime
```

## نصب ماژول

ریپازیتوری را مستقیماً داخل یکی از مسیرهای `addons_path` قرار دهید. بهتر است نام پوشه دقیقاً همین باشد:

```text
sun_macro_persian_localization
```

سپس Odoo را Restart کنید، Apps List را Update کرده و ماژول **Sun Macro Persian Localization** را نصب کنید.

پس از تغییر تنظیمات ظاهری، مرورگر را Refresh کنید.

## فونت‌ها

Vazirmatn و Shabnam با مجوز SIL Open Font License 1.1 داخل پروژه قرار گرفته‌اند. فونت IRANSans در نسخه عمومی GitHub قرار ندارد.
