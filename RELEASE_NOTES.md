# Sun Macro Persian Localization 19.0.2.0.0

First free public GitHub release of **Sun Macro Persian Localization** for **Odoo 19**.

## Included

- Optional RTL backend layout
- Vazirmatn and Shabnam font selection
- Optional Persian digits for common numeric fields
- Jalali/Gregorian Python conversion utilities
- Dedicated localization settings

## Dependency

```bash
pip install jdatetime
```

## Important Jalali note

This release includes Jalali utilities and configuration infrastructure. It does not claim a complete frontend replacement of Odoo's Date/DateTime picker.
