# Contributing

Contributions to Sun Macro Persian Localization are welcome.

## Guidelines

- Target Odoo 19.0.
- Keep changes focused on Persian localization.
- Do not commit proprietary fonts, credentials, database dumps, logs, or local paths.
- Test both a fresh install and a module upgrade when possible.
- For JavaScript/CSS changes, test with normal assets and `?debug=assets`.
- Keep source identifiers in English and user-facing Persian text clear and consistent.

## Bug reports

Please include the Odoo version, module version, browser, reproduction steps, and the relevant traceback or browser-console error.

By contributing, you agree that your code contribution may be distributed under LGPL-3.0. Font files must retain their own compatible licenses.
